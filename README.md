# Turing Smart Screen — Setup Guide (Improved)

This repository provides scripts to create and remove a Python virtual environment for a future application called "Turing Smart Screen". There is no application code yet; these steps prepare your system so you can plug the app in later.

If/when application code is added, update the sections "Run the App" and "Entry Points" with the real commands.

---

## Quick Start

- Supported OS: Linux with apt (Debian/Ubuntu) or dnf (Fedora/RHEL/CentOS/Rocky/Alma)
- Requires: sudo privileges and internet access

1) Clone and enter the repo
- git clone <this-repo-url>
- cd turing-smart-screen

2) Make scripts executable (once)
- chmod +x script/install_env.sh script/uninstall_env.sh

3) Install the environment
- ./script/install_env.sh

4) Activate the venv (in new shells)
- source venv/bin/activate

That’s it. You now have a ready Python environment with pinned dependencies.

---

## What the installer does
- Detects your distro and installs Python, dev headers, and graphics libs (jpeg/png/tiff/zlib/freetype/webp, Tk, ffi/ssl, DRM dev)
- Creates a virtual environment at ./venv
- Generates requirements.txt with pinned versions and installs them (force-reinstall semantics)
- Force-reinstalls ruamel.yaml, Pillow, and GPUtil to avoid import issues
- If configure.py exists in the repo root, runs it after activating the venv

## Optional: Install as a systemd service
A sample service unit is provided at script/turing-smart-screen.service. Adjust it before installation:
- Set User to your Linux username
- Set WorkingDirectory to the absolute path of your project (e.g., /opt/turing-smart-screen-python)
- Set ExecStart to the venv python followed by your app’s entry script (e.g., /opt/turing-smart-screen-python/venv/bin/python3 main.py)

Install the service (requires sudo):
- sudo cp script/turing-smart-screen.service /etc/systemd/system/turing-smart-screen.service
- sudo systemctl daemon-reload
- sudo systemctl enable --now turing-smart-screen.service

Common service commands:
- sudo systemctl status turing-smart-screen.service
- sudo journalctl -u turing-smart-screen.service -f
- sudo systemctl restart turing-smart-screen.service
- sudo systemctl disable --now turing-smart-screen.service

## Uninstall / Cleanup
- Deactivate venv (if active):
  - deactivate
- Remove venv and generated files:
  - ./script/uninstall_env.sh
- If you installed the systemd service:
  - sudo systemctl disable --now turing-smart-screen.service
  - sudo rm -f /etc/systemd/system/turing-smart-screen.service
  - sudo systemctl daemon-reload

## Troubleshooting
- apt PPA errors during update: the installer temporarily comments out sources in /etc/apt/sources.list.d/*.list and restores them after update
- Missing headers/build tools: verify your distro’s dev packages if builds fail
- Virtual environment not activating: run source venv/bin/activate from the repo root
- configure.py not found: expected unless you add such a file
