This repository currently contains scripts to set up and tear down a Python virtual environment for a (future) application called "Turing Smart Screen". ## Setup
From the repository root:

1) Make scripts executable (if needed):
- chmod +x script/install_env.sh
- chmod +x script/uninstall_env.sh

2) Install and configure the Python environment:
- ./script/install_env.sh

What the installer does:
- Detects your distro and installs Python, dev headers, and graphics libs (jpeg/png/tiff/zlib/freetype/webp, Tk, ffi/ssl, DRM dev).
- Creates a virtual environment at ./venv.
- Generates requirements.txt with pinned versions and installs them (force-reinstall to avoid conflicts).
- Explicitly force-reinstalls ruamel.yaml, Pillow, and GPUtil.
- If a file named configure.py exists in the repo root, it will be executed with python3 after the venv is activated.

3) Activate the virtual environment (if not already active):
- source venv/bin/activate

Note: The installer already activates the venv at the end, but you can re-activate it in new shells using the command above.

## Scripts
- script/install_env.sh
  - Detects distro (apt/dnf), updates system (with safeguards for apt PPAs), installs Python and dev libraries.
  - Creates and activates ./venv, generates requirements.txt, installs pinned Python deps.
  - Explicitly force-reinstalls ruamel.yaml, Pillow, and GPUtil to avoid import issues.
  - Activates the virtual environment at the end and attempts to run configure.py if present in the repo root.
- script/uninstall_env.sh
  - Deactivates the active virtual environment if one is active in the current shell.
  - Removes ./venv and requirements.txt (if present).
  - Optionally offers to remove certain system packages using apt (Debian/Ubuntu only), then runs apt autoremove. Other distros are not handled for removal.

## Troubleshooting
- apt PPA errors during update: the installer temporarily comments out sources in /etc/apt/sources.list.d/*.list to avoid failures and restores them after update.
- Missing headers or build tools: the installer attempts to install common dev packages for Pillow and other libs. If builds fail, verify your distro’s dev packages.
- Virtual environment not activating: ensure you are in the repo root and run: source venv/bin/activate
- configure.py not found: this is expected unless you add such a file to the project root.

## Maintenance
- To remove the environment safely:
